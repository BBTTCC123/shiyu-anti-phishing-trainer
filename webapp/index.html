        这是什么

        反钓鱼训练游戏：在拦截战里把涌来的消息拖进渔网或收件箱；在拆解台把破绽证物拖进类别槽； 在造浪者组装实验室拖卡调参造一封"钓鱼邮件"穿越扫描防线——或自由撰写。AI 蓝军安全官全程语音讲评， 最终生成五维「受骗风险画像」。

        合规声明

        • 全部样本均为虚构（人名、机构、域名、链接均为演示虚构），所有链接不产生真实跳转；
        • 本平台不提供任何消息发送 / 转发能力，界面全程带“教学模拟”水印；
        • 免登录、匿名使用，作答数据仅保存在你的浏览器本地；
        • 高发骗术类型参考国家反诈中心公开宣传内容。

        技术方案摘要

        • 题库：场景策略模板 + 结构化破绽标注（7 类），双人审核入库；
        • 判分：规则引擎（域名 / 链接 / 附件特征）+ 自建数据集训练的文本分类器；
        • 讲解：标注字段模板渲染为主，个性化建议由大模型流式生成；
        • 本演示版为纯前端离线实现（localStorage 存档），后端化部署方案见作品开发文档。
