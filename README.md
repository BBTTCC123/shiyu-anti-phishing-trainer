## 一句话主线

**识渔计划 = 反诈的「消防演练场」：先用手速练反应，再用证物练知识，再从攻击者视角练判断，最后用数据证明提升。**

记忆点：**不教结论，练肌肉记忆。**

> 反诈讲座告诉你「有诈骗」；这个作品让你在一封具体的邮件面前，反复练到「本能地看出来」。
> 四个模块就是这条主线的四步 —— **拦截战（练反应）→ 拆解台（练知识）→ 造浪者（练视角）→ 风险画像（证明效果）**，前后测把四步合成一个可量化的闭环。

## 一、作品简介

钓鱼攻击最可怕的地方，是**它看起来正常**。反诈讲座人人听过，但真收到一封「教务处」邮件时，判断靠的是从未被训练过的直觉。

《识渔计划》把这种判断力变成可以反复练习的游戏。作品用一个**攻防双视角**的闭环训练学生：

1. **先防守** —— 在时间压力下把涌入的消息拖进「渔网（钓鱼）」或「收件箱（正常）」（*拦截战*），再把拦下的钓鱼样本拆成证物碎片、拖进七类破绽槽位归类（*拆解台*）；
2. **再进攻** —— 切换到攻击者视角，拖卡装配「拟态皮肤 × 心理机制 × 技术手段」并用滑杆调参，亲手造一封钓鱼邮件去挑战内置 AI 防线（*造浪者·组装实验室*），或自由撰写一封由规则引擎逐词高亮判检；
3. **全程有反馈** —— AI 蓝军安全官打字机点评 + 本地语音讲评 + 快捷追问；可选云端 AI 智能体「渔安」支持自由对话与遭遇研判，断网自动回落本地规则版；
4. **练完有量化** —— 训练前后测对比，生成五维「受骗风险画像」（域名甄别 / 话术免疫 / 链接警惕 / 附件谨慎 / 紧迫感抗压）、段位、个性化建议与 **AI 训练诊断**（云端流式出具「总评 / 薄弱分析 / 训练处方」，离线回落规则版）。

作品默认全程离线、零网络请求（云端 AI 智能体 / 训练诊断为可选增强，未配置即纯离线），样本全部虚构并带「教学模拟」水印，链接不产生真实跳转。

## 三、核心功能

### 1. 拦截战（拖拽分拣 · 行为训练）

仿真邮件 / 短信 / 链接页卡片在限时中涌入，玩家把卡片**拖进左侧渔网（钓鱼）或右侧收件箱（正常）**。连击计分、数据完整度血条、超时漏网；键盘 `←` / `→` 亦可分拣。用真实的时间压力复现受骗情境。

### 2. 拆解台（证物归类 · 知识内化）

把拦截下的钓鱼样本拆成「证物碎片」（仿冒域名、短链、紧迫话术、附件、二维码……），**拖进七类破绽槽位**完成归类；首放命中计分、放错弹回并讲解，每件证物的归属与理由逐条展开。

七类破绽：域名仿冒 · 紧迫话术 · 冒充权威 · 链接不符 · 利诱钩子 · 附件风险 · 索要个人信息。

### 3. 造浪者 · 组装实验室（红蓝对抗 · 攻击者视角）

拖着 9 张「基因卡」（拟态皮肤 × 心理机制 × 技术手段）进装配槽，用三根滑杆连续调节 **伪装度 / 激进度 / 投放量**；预测仪给出带 **±8 误差**的检出率预测，投放后邮件飞越扫描光束揭晓真实检出率。也可**自由撰写**一封钓鱼邮件，由六类正则规则引擎（紧迫限时 / 利诱返利 / 冒充权威 / 索要敏感信息 / 可疑链接 / 附件诱导）逐词高亮判检。

### 4. AI 蓝军安全官 + 风险画像

全程打字机点评、浏览器本地语音播报（可开关）、快捷追问（本地知识库作答）。训练结束生成五维能力雷达、段位与个性化建议。

### 5. 清白之证（正常样本复盘 · 误报防治）

不只练「抓钓鱼」，也练「不冤枉正常」：每波拆解台与训练报告都会列出本波 / 本局的**正常样本**，用 `legitNotes` 逐条说明它为什么清白（发件域可信、链接与官网一致、无信息索取……）。把正常样本误判为钓鱼会记为**误报**，按目标元素（域名 / 链接 / 附件 / 话术）映射到对应能力维度扣分，并汇入报告末尾的「清白之证 · 正常样本复盘」。画像因此是**双向**的——既不放过钓鱼，也不冤枉正常邮件。

### 6. AI 智能体「渔安」（云端增强 · 三层兜底）

右下角悬浮入口打开对话面板：日常反诈问答 + 「遭遇研判」——用日常语言描述收到的可疑信息，渔安按「判定 / 依据 / 建议 / 提醒」四段给出分析。云端配置后走 OpenAI 兼容流式接口（`agent.js` + `config.js`，密钥混淆存储、源码不出现明文），未配置或断网时自动回落本地关键词规则引擎（`SCAM_PATTERNS`），离线可用。

### 7. AI 训练诊断（报告页 / 画像页）

把段位、五维得分、原始命中 / 漏判 / 误报计数、漏判类别分布与错题本打包成结构化快照，交给大模型流式出具「总评 / 薄弱分析 / 训练处方 / 一句提醒」；带「AI 生成 / 离线规则版」来源标识，按报告世代缓存（`report.at`），云端不可用回落 `DIM_ADVICE` 规则版建议。

### 8. 错题本 · 战绩海报

- **错题本**：分拣错误与拆解试错自动归档（localStorage `shiyu_wrong`），在画像页按错次排序展示并附对应破绽知识点；
- **战绩海报**：Canvas 现场绘制「段位 + 五维雷达 + 前后测战绩」海报，一键保存分享。

训练闭环设计：**前测（摸清基线）→ 训练（拦截 + 拆解）→ 后测（同难度不同题）→ 画像（量化提升）**。

**方式一（Windows，最快）**：双击根目录 [`启动识渔计划.bat`](启动识渔计划.bat)，脚本会自动启动本地静态服务并打开浏览器。

**方式二（任意系统）**：

```bash
cd webapp
python -m http.server 8765
# 浏览器访问 http://127.0.0.1:8765（建议手机竖屏，或浏览器开发者工具切换移动视口）
```

**方式三（部署）**：把 `webapp/` 整目录上传到任意静态托管（校园服务器 / GitHub Pages / 对象存储），入口 `index.html`，建议启用 HTTPS 后用二维码作为入口。无构建步骤、无环境要求。

> 注意：请勿用 `file://` 直接双击 `index.html`（部分浏览器会限制 localStorage 与语音），走本地服务器即可。

**校验题库数据（可选）**：

```bash
node tools/validate.js
```

## 七、技术架构

当前为「演示最优」的纯静态前端形态：单页应用（原生 JS，无框架、无构建链），部署成本趋近于零，离线可运行。

| 层 | 文件 | 职责 |
|---|---|---|
| 页面骨架 | `webapp/index.html` | 首页 / 拦截战 / 报告 / 造浪者 / 画像 / 关于 |
| 样式与动效 | `webapp/styles.css` | 深色科技风；拖拽吸附、槽位高亮、扫描光束、连击弹字等关键帧 |
| **数据层** | `webapp/data.js` | 20 个虚构样本（含破绽标注与 `legitNotes`）、战役波次编排（`CAMPAIGN`）、9 张基因卡、五维 / 类别常量、段位 |
| **逻辑层** | `webapp/app.js` | 拦截战状态机、拆解台拖放、组装实验室、安全官、雷达图、错题本、海报、清白之证、本地存档 |
| AI 增强层 | `webapp/agent.js` / `config.js` / `analyst.js` | 渔安智能体（对话 + 遭遇研判）与 AI 训练诊断：OpenAI 兼容流式封装，云端可选、离线回落本地规则版 |
| 工具 | `tools/validate.js` | 题库数据完整性静态校验（靶点 / `data-el` 锚点 / 维度映射 / 战役队列 / `legitNotes`） |

关键设计：

- **数据与逻辑完全分离**：加题 / 改题只动 `data.js`，不碰逻辑（样本 Schema 见 [`webapp/README.md`](webapp/README.md)）；
- **统一指针事件拖拽模型**：拦截卡 / 证物 / 基因卡三套拖拽复用同一模式，命中判定以指针坐标落点（`slotAtPoint`）为准，触屏与鼠标一致；
- **判定引擎**：拦截战 = 限时决策结算；拆解台 = 七类破绽的首放命中 / 试错计分；组装实验室 = 「基因基础检出 + 滑杆连续调制 + 预测仪噪声」的非线性对抗模型；自由撰写 = 六类正则规则引擎；
- **能力模型**：破绽类别 → 五维能力维度映射，前后测对比 + Canvas 手绘雷达图；
- **本地能力**：音效由 WebAudio 实时合成（无音频素材文件），语音采用浏览器本地 TTS；AI 智能体与训练诊断未配置云端时为**纯本地规则版**，配置云端后按需发起流式请求（密钥混淆存储于 `config.js`，删除该文件即整体回退纯离线），其余功能不发起任何网络请求；
- **本地存档**：进度与画像仅存 `localStorage`，匿名、不上传。

**后端化预留**（见 [`docs/02-开发文档.md`](docs/02-开发文档.md) §7）：话术出口 `Officer.play(script)` / `OFFICER_QA` 可替换为大模型流式接口；`launchAttack` 检出公式可替换为服务端分类器；固定题库 `CAMPAIGN` 可接「每日挑战」生成管线 —— 前端交互层无需改动。

## 十一、数据安全、隐私与合规

按赛项要求「涉及用户信息、网络通信、数据存储和智能算法的，应具有基本的数据安全、隐私保护和合规意识」，作品将合规内建为玩法：

- **默认零外部依赖 / 云端可选透明**：未配置云端时运行不发起任何外部网络请求、无第三方追踪；部署者如主动配置云端大模型（`config.js`，密钥混淆存储），仅 AI 智能体与训练诊断按需发起请求，且只发送游戏内训练统计数据（不含身份信息），请求失败自动回落纯本地规则版；
- **AI 使用透明**：按竞赛要求提交《AI 工具使用说明》，说明生成式 AI 在代码辅助环节的使用范围与人工审核流程（见 [`docs/04-AI工具使用说明.md`](docs/04-AI工具使用说明.md)）。

## 十二、创新点

自主选定 **4 条核心创新**（与顶部速览一致），每条按「人话解释 → 为什么算创新」展开。

### 1. 攻防双视角训练法

- **人话**：别人只教「认钓鱼」，它让你亲手造一封钓鱼邮件去撞防线。
- **为什么算创新**：多数反诈产品止步于「识别」；本作品让用户切换到攻击者视角，用角色代入理解「为什么这封能骗到人」，防御直觉才扎得深。攻防转换在同类反诈产品中少见。

### 2. 证物化拆解交互

- **人话**：不问「这封是不是钓鱼」，而是问「哪个地方是破绽」，拖进对应的槽。
- **为什么算创新**：把判定粒度从「整封对错」细化到「逐个破绽」，归类动作本身就是知识结构化的过程；也让系统能区分「蒙对」与「真会」，讲解能精确到每一处。
- **双向判定扩展（清白之证 · 误报防治）**：不只拆「破绽」，也为正常样本出具「清白之证」——逐条说明它为什么可信；误把正常样本判成钓鱼会计为**误报**并按目标元素映射到能力维度。多数反诈训练只测「有没有抓到钓鱼」，本作品同时测「有没有冤枉正常」，把误报防治纳入能力画像。

### 3. 带误差的对抗预测 + 连续参数空间

- **人话**：滑杆连续调参 → 预测仪给 ±8 的区间 → 投放后加噪声出真实结果。
- **为什么算创新**：预测 ≠ 结果，堵死「背答案」；把「攻击构造」从离散选卡变为连续权衡（伪装度 × 激进度 × 投放量非线性耦合），用户必须理解参数之间的关系，而不是找一个唯一最优解。

### 4. 合规内建为玩法 + 零依赖实现

- **人话**：全虚构样本、禁真实跳转、教学模拟水印、本地匿名存档；AI 角色与音效均有完整本地实现，云端大模型仅作可选增强。
- **为什么算创新**：「骗子视角」的教学内容天生敏感，本作品把风险从源头掐死 —— 安全护栏是产品设计，不是事后补丁；工程上零后端、无构建链、离线可运行，演示默认零网络零延迟，同时已落地大模型升级位（配置即启用，断网即回退）。
