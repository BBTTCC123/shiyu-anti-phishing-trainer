## 1. 工具名称

大语言模型编程助手（GLM 系列等），用于**工程开发环节的代码生成辅助**。

**未使用 AI 生成图像 / 音频素材**：界面图形为原生 Emoji 与 CSS / SVG 动效，音效由 WebAudio 程序合成，作品不含 AI 生成的图像、音频或视频素材，因此本作品不涉及「生成合成内容标识」的额外义务。

## 2. 使用环节

仅限**工程开发环节**：

- 前端脚手架 / 模板代码、样式片段；
- 正则规则草案、文档初稿的生成辅助。

**未用于**：作品玩法设计、样本与破绽标注、判定规则、讲解文案、评测设计 —— 上述均由团队人工设计与编写。

## 3. 主要工作流（提示词工作流）

采用「**人定架构与验收标准 → 模型生成候选实现 → 人工审查合入**」的迭代流程：

1. 团队确定模块职责、数据 Schema 与验收标准；
2. 由模型生成候选实现 / 草案；
3. 人工逐段审查、重写与合入；关键交互（拖拽命中判定、扫描束结算、计分公式）由团队定义算法与边界条件。

## 4. 人工筛选与修改过程

- 所有生成代码均经人工评审、重写与**自动化回归测试**（浏览器全流程：四波分拣 / 拆解归位 / 实验室投放 / 自由撰写 / 报告生成）；
- 修复了模型初版中的两处交互缺陷：① 拖拽元素过渡动画导致快速拖放丢失；② 合成指针事件下 `setPointerCapture` 抛异常；
- 建立了「题库数据校验脚本」`tools/validate.js`，用机器校验替代人工肉眼核对靶点与映射的一致性。

## 5. 团队原创贡献

以下均**由团队完成，非 AI 生成**：

- 选题与「攻防双视角训练法」设计；
- 样本库（20 题）与七类破绽体系、五维能力模型；
- 全部判分规则、计分公式与演示文案；
- 评测方案设计与文档撰写；
- 合规设计与安全护栏（全虚构样本、禁真实跳转、教学模拟水印、匿名本地存档）。

## 6. 版权与数据合规情况

- 作品**不含任何第三方版权素材**（图形为 Emoji / CSS / SVG，音效为程序合成，语音为浏览器本地 TTS）；
- 全部样本**虚构**，不含真实机构、真实域名、真实个人信息；
- 运行时**无外部网络请求**，不采集用户身份信息，数据仅存本地；
- AI 辅助范围仅限开发环节，未参与生成对外呈现的合成内容。
