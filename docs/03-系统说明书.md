## 1. 系统说明

### 1.1 系统定位

《识渔计划》是一个**运行在手机浏览器里的反钓鱼诈骗训练系统**。系统以「游戏化行为训练」替代「单向反诈宣讲」，让用户在仿真的邮件、短信、链接页中反复练习识别钓鱼攻击，对每一处误判给出逐条讲解，并在训练前后用同难度题目对比，生成五维「受骗风险画像」。

### 1.2 目标用户

| 层级 | 对象 | 场景 |
|---|---|---|
| 直接用户 | 在校大学生，重点为大一新生 | 个人自测、宿舍 / 班级对抗赛 |
| 推广用户 | 高校保卫处、辅导员 | 新生安全教育月班级演练 |
| 延伸用户 | 中学信息科技教师 | 网络安全 / AI 素养课堂教具 |

### 1.3 功能模块

| 模块 | 入口 | 功能 |
|---|---|---|
| 首页 / 导航 | `#v-home` | 进入各模式、显示当前段位、查看作品说明 |
| 拦截战 | `#v-game` | 限时拖拽分拣（渔网 / 收件箱）、连击、血量、超时漏网 |
| 拆解台 | `#v-game`（同屏切态） | 证物拖进七类破绽槽、首放命中计分、放错弹回、逐条讲解；附「清白之证」正常样本说明 |
| 清白之证 · 误报防治 | `#v-game` / `#v-report`（同屏切态） | 渲染正常样本教学说明（`legitNotes`）；误报（正常判为钓鱼）映射到能力维度并计入画像 |
| 造浪者 · 组装实验室 | `#v-attack` | 拖卡装配 + 三滑杆调参 + 预测仪 ±8 + 投放扫描结算 |
| 造浪者 · 自由撰写 | `#v-attack`（同屏切态） | 自写钓鱼邮件 → 规则引擎逐词高亮 → 检出率与讲评 |
| AI 蓝军安全官 | 全局浮层 | 打字机点评、语音播报（可开关）、快捷追问 |
| 训练报告 | `#v-report` | 前后测识别率对比、段位、五维雷达、薄弱项、建议 |
| 我的画像 | `#v-profile` | 维度得分、历史战绩、清空训练数据 |
| 关于本作品 | `#v-about` | 合规声明、技术方案摘要 |

功能模块关系：**首页**是唯一入口，**拦截战 → 拆解台 → 报告**构成防守训练主线，**造浪者**是独立的进攻对抗线，**安全官**贯穿全程，**画像**沉淀长期数据。

### 1.4 系统边界与运行环境

- 运行环境：现代移动端 / 桌面端浏览器（Chrome / Edge / Safari 现代版本）；
- 依赖：无外部库、无后端、无网络请求；音效用 WebAudio 合成，语音用浏览器本地 TTS；
- 数据：仅使用浏览器 `localStorage` 保存进度与画像，键名 `shiyu_v3`；
- 边界：系统**不发送任何消息、不跳转外部链接、不采集个人信息**，全部样本为虚构教学素材。

## 2. 功能演示

### 2.1 演示路径（约 5 分钟）

1. **首页 → 拦截战**：进入第一波「前测侦察」，演示把一张钓鱼卡拖入渔网（命中、连击 `x3` 弹字）、把一张正常卡拖入收件箱，再让一张卡超时漏网（血条下降 + 震屏）；
2. **拆解台**：把证物拖进「域名仿冒」槽命中；故意放错一次，观察弹回与提示；打开判定讲解逐条讲解；
3. **造浪者 · 组装实验室**：拖三张基因卡入装配槽，拉高「伪装度」观察预测仪变化，点击投放 → 扫描光束 → 揭晓真实检出率 → 安全官语音点评；
4. **造浪者 · 自由撰写**：输入一段含「紧迫 + 利诱 + 链接 + 索要验证码」的钓鱼邮件 → 逐词高亮 → 检出率；
5. **训练报告 / 我的画像**：查看前后测对比、五维雷达、段位与建议。

## 3. 技术架构

### 3.1 总体架构（当前形态：纯静态前端单页应用）

```
┌────────────────── 浏览器（移动优先，单页应用）──────────────────┐
│  index.html   页面骨架（6 个 view 分区）                          │
│  styles.css   深色科技风样式 + 关键帧动效                          │
│  data.js      数据层：样本 / 战役 / 基因卡 / 维度 / 段位常量        │
│  app.js       逻辑层：状态机 / 交互 / 判定引擎 / 渲染 / 本地存档    │
│  ── 本地能力：WebAudio 音效 · Web Speech 语音 · Canvas 雷达图 ──   │
└───────────────────────────────────────────────────────────────┘
        （零后端、零外部依赖、无网络请求，可整目录静态托管）
```

### 3.2 关键技术点

| 点 | 实现 |
|---|---|
| 单页路由 | `show(id)` 切换 `section.view`，无框架、无构建链 |
| 拖拽交互 | 统一 Pointer Events 模型；`slotAtPoint(x,y,selector)` 以指针落点判定命中，触屏 / 鼠标一致 |
| 拦截战 | 状态机 `G`（`waveIdx / cardIdx / lives / score / combo / answers / sortLog`）+ 200ms 计时 tick |
| 拆解台 | 由 `redflags` 生成证物，首放命中计分、试错弹回；`data-el` 文本锚点与 `parts.id` / `meta.addrId` 统一解析（`partOf`），证物标签显示真实文案 |
| 清白之证 · 误报防治 | 正常样本的 `legitNotes` 渲染进拆解台与训练报告；误报按 `FA_DIM_BY_PARTTYPE` 映射到能力维度并累加 `fa`，驱动画像扣分 |
| 组装实验室 | 基因卡基础检出分 + 三滑杆连续调制 + 预测仪噪声（±8）→ 非线性检出模型 |
| 自由撰写 | 六类正则规则引擎 `FREE_RULES` 逐词匹配、累计检出、命中高亮 |
| 能力画像 | 破绽类别 → 五维映射（`DIM_OF_CATEGORY`），前后测对比 + Canvas 手绘雷达 |
| 本地存档 | `localStorage["shiyu_v3"]`，匿名、不上传 |

### 3.3 数据模型（关键结构）

样本 Schema（`data.js`，与后端化后的题库表结构同构）：

```jsonc
{
  "id": "em1", "carrier": "email|sms|linkpage", "difficulty": 1,
  "phishing": true, "scene": "场景名",
  "meta": { "from": "…", "addr": "…", "subj": "…", "time": "…" },
  "parts": [ { "t": "p|link|attach|qr|btn|field", "id": "靶点id", "text|html": "…" } ],
  "redflags": [ { "category": "7类之一", "target": "靶点", "explain": "讲解文案" } ],
  "legitNotes": [ { "target": "…|null", "note": "正常样本的教学说明" } ]
}
```

靶点解析规则（与 `app.js` 的 `partOf()` 一致）：邮件样本的 `{id}-addr` 指向 `meta.addr`、链接页样本的 `{id}-url` 指向 `meta.url`（由 `data.js` 末尾自动派生），其余靶点为 `parts[].id` 或正文内 `<span data-el="…">` 锚点。

### 3.4 后端化升级路线（可选，见开发文档 §7）

前端已预留三个替换点，交互层无需改动：

1. 话术出口 `Officer.play(script)` / `OFFICER_QA` → 后端大模型流式接口；
2. `launchAttack` 的检出公式 → 服务端分类器（自建数据集训练的轻量文本模型）；
3. 固定题库 `CAMPAIGN` → 题库 API（「每日挑战」动态出题）。

## 4. 测试说明

### 4.1 测试环境

- 浏览器：Chrome / Edge（Windows），Safari（iOS）；移动视口 390×844；
- 运行方式：本地静态服务器（`python -m http.server`）与静态托管；
- 自动化/脚本：Node.js（语法检查与数据校验）。

| 编号 | 测试项 | 方法 | 结果 |

| T4 | 拆解台归类 | 证物拖入对应槽位、首放命中、放错弹回 | 通过 |
| T5 | 组装实验室 | 拖卡装配、滑杆实时预测、投放噪声结算、扫描束动效 | 通过 |
| T6 | 自由撰写判检 | 规则引擎命中高亮、检出率结算 | 通过 |
| T7 | 报告 / 画像 | 前后测对比、五维雷达、段位、建议 | 通过 |

### 4.3 兼容性与降级

- 现代 Chrome / Edge / Safari 正常；
- 语音（Web Speech）在部分 Linux 浏览器不可用，会**静默降级为纯文字**，不影响主流程；
- 拖拽元素若带 `transition: transform` 会丢快速拖放（已禁用并加 `.dragging` 类）；合成 PointerEvent 下 `setPointerCapture` 抛错（已 try/catch，真实输入不受影响）。

### 4.4 已知限制

- 题库为 20 题精标样本；「每日挑战」动态出题需后端 LLM 管线；
- 判分为前端规则引擎，后端化后可替换为自建数据集分类器；
- 语音为浏览器本地 TTS，音色依系统而定。
