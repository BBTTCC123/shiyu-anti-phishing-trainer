# 《识渔计划》演示视频脚本（3–5 分钟）

> 用途：竞赛提交材料「功能演示」的视频分镜。
> 录制建议：真机（手机竖屏）录屏为主，可穿插 1–2 个操作特写；分辨率 1080×1920，配音 + 字幕。

| 时段 | 画面 | 要点 |
|---|---|---|
| 0:00–0:20 | 黑屏字卡 → 首页 | 字卡：「你上个月收到的可疑邮件，敢说一定分得清吗？」→ 进入游戏首页 |
| 0:20–1:30 | 拦截战 | 三张卡演示：拖入渔网（命中，连击 `x3` 弹字）；一张超时漏网（血条 −15%、震屏） |
| 1:30–2:30 | 拆解台 | 证物拖入「域名仿冒」槽命中；一次故意放错弹回；打开判定讲解逐条讲解 |
| 2:30–3:30 | 组装实验室 | 拖三张基因卡入装配槽；拉高「伪装度」（观察预测仪变化）→ 投放 → 扫描光束 → 揭晓真实检出率 → 安全官语音点评 |
| 3:30–4:10 | 自由撰写 | 输入一段自写钓鱼邮件 → 命中词高亮 → 检出率与判检讲评 |
| 4:10–4:40 | 风险画像 | 前后测识别率对比、五维雷达、段位 |
| 4:40–5:00 | 收尾 | 主张字卡：「不教结论，练肌肉记忆」＋团队信息 |

## 录制注意

- 使用手机竖屏（或浏览器移动视口）；
- 语音旁白与游戏内 TTS 错开，避免叠音；
- 演示用样本全部为虚构教学素材，画面保留「教学模拟」水印；
- 关键交互（连击弹字、扫描光束、雷达图）保持清晰可辨识；
- 若时长紧张，优先保「拦截战 → 拆解台 → 组装实验室 → 画像」四段。
