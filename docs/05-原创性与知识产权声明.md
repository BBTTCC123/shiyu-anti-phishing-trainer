## 一、原创性声明

本参赛作品《识渔计划 —— 反钓鱼攻防训练营》为团队**原创设计并开发**，未抄袭、仿冒或侵害他人知识产权。

- 作品使用的开源技术仅为通用开发库与浏览器标准 API（原生 JavaScript、CSS、HTML5、WebAudio、Web Speech、Canvas）；
- 作品中**全部样本为虚构**，不涉及任何真实机构、真实域名与真实个人；
- 作品的玩法设计、样本与破绽标注、判定规则、文案与数据结构均由团队独立完成；
- 作品开发过程中使用了大语言模型工具进行代码生成辅助，具体范围与人工作用见 [`04-AI工具使用说明.md`](04-AI工具使用说明.md)。

团队承诺对上述声明的真实性负责。

## 二、知识产权说明

1. 本作品知识产权归参赛团队及其所在学校按学校相关规定享有；
2. 参赛即授权竞赛组委会在大赛宣传、展示与教学推广范围内非商业性使用本作品（含演示视频与截图）；
3. 作品**不含第三方版权素材**：界面图形为原生 Emoji 与 CSS / SVG 动效，音效为 WebAudio 程序合成，语音为浏览器本地 TTS；
4. AI 辅助仅用于开发环节，未参与生成对外呈现的合成内容（详见 AI 工具使用说明）；
5. 团队成员之间对作品的贡献与权利分配由团队内部约定。

## 三、数据与内容合规声明

- 作品不采集任何个人身份信息，免登录、匿名使用；
- 作答数据仅保存在用户浏览器本地（`localStorage`），不上传、不联网；
- 作品不提供消息发送 / 转发能力，所有链接仅在产品内本地演示，不产生真实跳转；
- 所有样本界面全程带「教学模拟」水印；
- 高发骗术类型参考国家反诈中心公开宣传内容，仅作教育用途。
