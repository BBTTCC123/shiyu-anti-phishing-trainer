# 识渔计划 · 微信小程序版（miniprogram/）

与 H5 版（../webapp/）同数据同玩法的原生小程序实现：拦截战（触摸拖拽分拣）→ 拆解台（证物拖放归类）→ 造浪者实验室（点选装配 + 原生滑杆 + 噪声结算；含自由撰写）→ AI 智能体「渔安」（本地知识库；云模式需配域名）→ 画像（Canvas 2D 雷达 + 错题本）。

## 运行

1. 安装「微信开发者工具」（稳定版）。
2. 导入本项目目录 `miniprogram/`——测试号模式无需 AppID（`project.config.json` 已设 `touristappid`）；正式发布替换为团队 AppID。
3. 工具内「预览」扫码即玩；真机调试建议打开「真机调试 2.0」验证拖拽手感。

## 与 H5 版的差异（有意为之）

| 点 | H5 | 小程序 |
|---|---|---|
| 基因装配 | 拖拽入槽 | 点选装配（触屏小目标拖拽易误触，点选更稳） |
| 滑杆 | 自绘 | 原生 slider 组件（跟手更佳） |
| 语音 | Web Speech | 未内置（Web Speech 不可用；如需可接微信同声传译插件，见下） |
| 扫描束动画 | CSS 动画 | 简化为结算面板 |
| 智能体云模式 | 浏览器内配置 BaseURL/Key | 需在小程序后台配置 request 合法域名后由代码内接入（见 utils 注释与发布指南） |

## 数据同步

题库唯一权威源是 `../webapp/data.js`；`utils/data.js` 为同步副本（当前 20 题已同步）。改题流程：改 H5 版 → 运行 `node ../tools/validate.js` 校验（在项目根目录运行 `node tools/validate.js`）→ 将 `SAMPLES/CAMPAIGN/GENES/FREE_RULES` 同步到本文件。

## 发布（要点，详见 ../小程序发布指南.md，依据 2026-10-13 官方文档核实）

- 形态选**小程序**（勿选游戏类目——一经选择不可改回其他小程序类目）；
- 一期推荐**个人主体**：0 元、免认证，类目选"工具-信息查询"；**个人主体无 web-view、无深度合成（AI问答）类目**——智能体页一期建议从 `app.json` 移除（本地代码保留，二期非个人主体再上）；
- **ICP 备案强制**（新注册小程序须备案才能上架，预留 3–22 个工作日，含 12381 短信核验）；
- **《小程序用户隐私保护指引》必须配置**（2023-10-17 起强制，未配置提审被拦截）；
- 若二期开启智能体云模式：大模型 API 域名须 HTTPS+ICP 备案并加入 request 合法域名白名单（不支持通配）。

## 可选增强（接手备忘）
